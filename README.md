# RB TOP UP — Android-ready starter project

A simple Flutter starter for a Bangladesh-focused game top-up storefront.

## Included
- RB TOP UP branding
- Diamond package selection
- Game + Player ID form
- bKash/Nagad payment-method selection
- Order ID generation
- Local order history/status demo
- No real-money payment processing or game-account delivery API is included

## Run
1. Install Flutter (stable).
2. Run `flutter pub get`.
3. Run `flutter run` or build with `flutter build apk --release`.

For production, connect the order creation flow to your own backend and an authorized payment/game top-up provider.
